# HAUVIE account override

Extends the approved storefront override, not the generated master palette.

- White form surface; near-black headings and lime primary submit button.
- The form is the primary surface. No large image or marketing block before it.
- Separate Đăng nhập / Đăng ký tabs; visible labels; 16px inputs; 48px controls.
- Allow paste and password managers, with current-password / new-password autocomplete.
- Password visibility toggle has an accessible name and pressed state.
- Preserve input on errors, show field errors and a focused error summary.
- Submission has loading feedback and a synchronous duplicate-submit guard.
- Authentication uses Supabase email/password, never ChatGPT or localStorage credentials.
