# HAUVIE storefront override

The user's approved brand overrides the generated master palette and font suggestions.

- White and near-black surfaces, lime #dfff00 accent with black text.
- Retain the existing Geist font; no extra font or animation downloads.
- Clear Vietnamese labels: visible Đăng nhập, search submit and shopping bag count.
- Separate desktop category navigation from the search/account row. Mobile search stays visible.
- Equal image frames in each collection; use contain for product packshots.
- Keep category images correctly associated; label unavailable collections without unrelated photos.
- 44px primary controls, visible keyboard focus, reduced-motion support.
- Native links preserve browser navigation while the framework router is incompatible.
